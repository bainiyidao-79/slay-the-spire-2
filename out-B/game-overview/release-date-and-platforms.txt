<h2>What &quot;Early Access&quot; Means Right Now</h2>
<ul>
<li>The Early Access build is already deep: five playable characters, four-player online co-op, enchantments, branching act variants and Ascension modifiers.</li>
<li><strong>Beta patches land roughly every two weeks</strong>, mixing balance changes and new art, and the beta branch periodically graduates to the main branch. See the <a href="/news/patch-notes">Patch Notes page</a> for the current version.</li>
<li>Content and balance are still moving — a build that is top-tier this patch can shift the next one, which is exactly what our <a href="/cards/tier-list">Tier List</a> tracks.</li>
</ul>
<h2>The Steam Store Page Facts</h2>
<ul>
<li><strong>Price:</strong> $24.99 one-time purchase (see <a href="/game-overview/price-and-editions">Price &amp; Editions</a>).</li>
<li><strong>Languages:</strong> 14 interface languages at Early Access.</li>
<li><strong>Steam Deck:</strong> Verified — the full game is playable on the Deck out of the box.</li>
</ul>
<h2>Console and Mobile: What We Actually Know</h2>
<p>No release windows, target quarters or &quot;planned for 2027&quot;-style promises have been announced for Switch, Switch 2, PS5, Xbox or mobile versions. Community discussion about console versions (and whether PC–console crossplay will follow them) is active, but Mega Crit has not published dates — anything you read beyond &quot;TBA&quot; is speculation. The same goes for the 1.0 date: Early Access is expected to grow toward a full release, but no date has been committed.</p>
